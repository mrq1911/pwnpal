# Screenshots

Drop the release screenshots / demo here. The README and any catalog listing reference these
exact filenames:

- `home.png` — home screen / persona
- `list.png` — Recent APs list
- `detail.png` — AP detail page
- `demo.gif` — short capture of it running

Flipper screen is 128x64; upscale with nearest-neighbour (no blur) for crisp pixels.

**Sanitize before committing — nothing that identifies the owner:**
- no real SSIDs or BSSIDs (use a lab AP, or blur/rename them)
- no GPS coordinates, home distance, or map QR of a real location
- no device serials or personal names

If a real network or location is visible in a frame, don't commit it.
